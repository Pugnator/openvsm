# OpenVSM v0.7 Lua compatibility

The v0.7 rewrite uses the C++ Proteus SDK interfaces. The old uncompiled C
binding was removed because it depended on a private model layout and the
deleted `vsmapi.h`; its presence did not make any of these globals executable.

Status meanings:

- **Supported**: registered and covered by a Lua contract test.
- **Planned**: belongs to an open focused issue or an active replacement API.
- **Deliberately removed**: unsafe, misleading, or superseded; migration is noted.
- **Proteus-host-only**: intentionally unavailable to portable model scripts;
  calling the compatibility stub raises a descriptive Lua error.

## Constants

| Legacy globals | v0.7 status | Notes |
| --- | --- | --- |
| `UNDEFINED`, `TSTATE`, `FSTATE`, `PLO`, `ILO`, `SLO`, `WLO`, `FLT`, `WHI`, `SHI`, `IHI`, `PHI`, `WUD`, `SUD` | **Supported** | Values come from `vsm.hpp`. They are registered before the model script executes. |
| `NOW`, `NSEC`, `USEC`, `MSEC`, `SEC` | **Supported** | Picosecond units. `NSEC` is corrected from the legacy value to 1,000 ps. |
| `TTL`, `CMOS`, `I2L` | **Supported** | Compatibility values `0`, `1`, and `2`. Pin state mappings remain explicit in v0.7. |

## Functions

| Legacy global | v0.7 status | Migration/behavior |
| --- | --- | --- |
| `state_to_string(state)` | **Supported** | Returns the legacy names for every SDK state constant. |
| `info(text)` | **Supported** | Forwards safely to `IINSTANCE::log`. |
| `message(text)` | **Supported** | Forwards safely to `IINSTANCE::message`. |
| `warning(text)` | **Supported** | Forwards safely to `IINSTANCE::warning`. |
| `error(text)` | **Deliberately removed** | v0.7 preserves Lua's standard error function. Use `vsm_error(text)` for `IINSTANCE::error`. |
| `get_string_param(name)` | **Supported** | Uses `IINSTANCE::getstrval`. |
| `get_num_param(name)` | **Supported** | Uses `IINSTANCE::getnumval` and returns a Lua number. |
| `get_bool_param(name)` | **Supported** | Uses `IINSTANCE::getboolval` and returns a Lua boolean. |
| `get_init_param(name)` | **Supported** | Uses `IINSTANCE::getinitval`. |
| `get_hex_param(name)` | **Supported** | Uses `IINSTANCE::gethexval`. |
| `systime()` | **Supported** | Returns the current absolute simulation time in picoseconds. |
| `set_callback(time, event_id)` | **Supported** | Schedules the model through `IDSIMCKT::setcallback`; dispatch is tracked by #48. |
| `set_bus`, `get_bus` | **Deliberately removed** | Use declarative `device_buses` and native bus objects from #54. Compatibility stubs explain the migration. |
| `create_debug_popup`, `create_memory_popup`, `create_source_popup`, `create_status_popup`, `create_var_popup` | **Proteus-host-only** | Compatibility stubs raise explicit errors. The pointer-heavy UI API is not part of portable v0.7 models. |
| `delete_popup`, `set_memory_popup`, `repaint_memory_popup`, `print_to_debug_popup`, `dump_to_debug_popup`, `add_source_file` | **Proteus-host-only** | Compatibility stubs raise explicit errors for the same reason. |

## Objects, callbacks, and legacy modules

| Surface | v0.7 status | Notes |
| --- | --- | --- |
| Pin objects | **Supported** | Registered from `device_pins`; timing correction is tracked by #44. |
| Native bus objects | **Planned** | Implemented by #54; legacy table-wide `set_bus`/`get_bus` are not restored. |
| `device_init`, `device_simulate`, `timer_callback` | **Planned** | Stack safety and dispatch are tracked by #48 and #49. |
| Pin/bus event objects | **Planned** | Tracked by #18. |
| Precompiled device scripts | **Planned** | The CMake bytecode path is retained, but the old C module loader was incompatible. |
| `uart` module | **Supported** | Shipped as ordinary Lua source under `model/lua/modules`; uses the v0.7 callback API and initializes the line idle-high. |
| `custom` and `fifo` bundled modules | **Deliberately removed** | Their generated legacy C modules were not carried into the C++ rewrite. Models should provide ordinary Lua modules explicitly. |

## Migration rules

Model scripts can use supported globals at top level because the API is
registered before the script is loaded. Unsupported legacy calls are functions,
not silent `nil` globals, and fail with a message naming the v0.7 replacement or
restriction. Lua's standard libraries are left intact.
